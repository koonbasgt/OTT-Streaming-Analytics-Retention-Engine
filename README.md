# OTT-Streaming-Analytics-Retention-Engine
This project is a comprehensive enterprise-grade data analytics pipeline designed for global OTT streaming platforms. It focuses on evaluating financial yield, optimizing customer acquisition, and mitigating user churn probability through data-driven strategies.
​🎯 Key Objectives:
​Financial & Unit Economics Analysis: Evaluates Customer Lifetime Value (LTV) against Customer Acquisition Cost (CAC) to measure acquisition efficiency across multiple global regions.
​Churn Risk Scoring Model: Implements a rule-based scoring system to assess user churn probability based on behavioral indicators, including low watch hours, high support ticket frequency, and tenure length.
​Strategic Turnaround Framework: Proposes a data-backed retention strategy ("Option B: Optimize first, sunset later") to maximize content ROI and user engagement before asset deprecation.
​🛠️ Tech Stack & Metrics:
​Python (Pandas, NumPy): Data simulation, processing, and quantitative analysis.
​Core Metrics: LTV, CAC, LTV:CAC Ratio, and Churn Risk Probability.
​Platform: GitHub for version control, repository structuring, and professional technical documentation.
​This project demonstrates strong capabilities in business analytics, financial modeling, and translating raw data into actionable enterprise strategies.
